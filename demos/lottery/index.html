奖池与库存

活动规则

  • 每位会员每日 3 次抽奖机会，分享可额外获得 1 次（演示中未开启）。
  • 奖品数量有限，抽中后库存实时扣减，库存为 0 的奖品自动从奖池移除。
  • 实物奖品在活动结束后 7 个工作日内寄出，优惠券实时到账。

#奖品类型权重实际概率库存已抽
权重为相对值，不需要凑成 100；实际概率 = 本奖品权重 ÷ 所有有库存奖品的权重之和。库存为 0 时该奖品权重自动置为 0，不会出现「抽中但发不出」。

并发与防刷（演示说明）

DESIGN NOTE
库存扣减
用 UPDATE prize SET stock = stock - 1 WHERE id = ? AND stock > 0 判断受影响行数，或 Redis DECR 后回补，避免超发。

幂等
每次抽奖带 requestId，同一 ID 重复请求直接返回上次结果，防止网络重试造成重复发奖。

限次
按 memberId + 活动ID + 日期 计数，先 INCR 再判断是否超过 3 次，超限立即回退。

概率
先按权重选出奖品，再尝试扣库存；扣减失败则重选一次，仍失败则返回「谢谢参与」。
