SERVICES / 01

产品与服务

按业务场景分三类：线上业务、系统互通、基础设施。可以只做一项，也可以从开发到上线一起接。

01线上业务

微信小程序开发

从零做一个小程序，或把现有业务搬进微信。含商品、下单、支付、会员、预约等常见模块。

  • 商城 / 点单 / 预约 / 会员卡
  • 对接微信支付与订阅消息
  • 提审、发布、后续改版
02系统互通

接口 / API 与第三方对接

把一个系统里的数据安全地送到另一个系统，包含协议转换、字段映射、失败重试与日志。

  • 支付、短信、物流、电子发票
  • ERP / 进销存 / 财务系统对接
  • 对账、回调、幂等与补偿
03基础设施

云服务器部署运维

阿里云 / 腾讯云等主流云厂商都能配：买好机器之后的那部分，环境安装 Nginx / MySQL / Redis / Docker、域名与备案指引、部署上线、SSL、备份监控、故障处理。

  • Nginx / MySQL / Redis / Docker
  • HTTPS 证书与续期提醒
  • 定时备份与告警
04基础设施

企业邮箱搭建

用企业域名做邮箱，把 MX、SPF、DKIM、DMARC 配到能正常收发、不进垃圾箱。

  • 域名解析全套记录配置
  • 发信认证与反垃圾策略
  • 客户端与网页端收信设置
05线上业务

企业官网与后台管理系统

官网负责对外介绍，后台负责对内管数据。两边可以一起做，也可以只补其中一块。

  • 响应式官网、产品页、表单
  • 权限、角色、操作日志
  • 数据导入导出与报表
06长期支持

既有系统维护与功能增改

接手别人做了一半或跑了几年没人管的系统，先摸清结构，再做修复、迁移和功能扩展。

  • 故障排查与性能优化
  • 老旧页面 / 框架升级
  • 数据迁移与结构梳理

PROCESS / 03

服务流程

先把事情说清楚再动手。每一步都有明确产出，不满意可以在对应环节停下。

1

需求沟通

聊清业务场景、用户是谁、必须有哪些功能，判断是改造还是新建。

2

方案与报价

给出功能清单、技术方案、工期与费用，写清做什么、不做什么。

3

开发

分阶段交付可点开的页面，过程中随时看到进度，不停在最后一天才给东西。

4

验收交付

按清单逐项验收，交付源码、部署文档与账号权限，线上跑通为止。

5

售后

上线后的问题处理与改动支持，按次或按周期约定，不做交付即失联。
